# VisionForge roadmap

## Current status

- Desktop app shell and responsive dashboard are in place.
- Model catalog includes popular YOLO and lightweight alternatives.
- Dataset scanning, validation, and annotation workspace are implemented.
- Training pipeline supports configuration and live progress monitoring.
- Live inference supports webcam, image, and video inputs with custom model loading.

## Next priorities

- Improve annotation tooling with stronger box editing and label persistence.
- Add export-ready dataset split generation for YOLO and COCO workflows.
- Extend inference preview with clearer overlay drawing and saved result export.
- Review model compatibility for edge-oriented families and custom .pt checkpoints.
